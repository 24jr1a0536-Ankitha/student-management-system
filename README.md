# AI Interview Preparation Platform

## Description
This project is a MERN Stack based Interview Preparation Platform.

## Features
- Resume Upload
- Resume Analysis
- Technical Quiz
- Mock Interview
- Feedback Page

## Tech Stack
- React.js
- Node.js
- Express.js
- Multer
- Axios

## Folder Structure
client/
server/

## Installation

### Client
cd client
npm install
npm start

### Server
cd server
npm install
node server.js
